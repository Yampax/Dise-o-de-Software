La clase AuditorSeguridad implementa el patrón Singleton para garantizar que exista una única instancia encargada de registrar las acciones críticas del sistema. Para ello, utiliza un constructor privado y un método estático getInstancia() que crea la instancia únicamente cuando es necesaria. El uso de synchronized permite controlar el acceso concurrente y evitar conflictos al registrar eventos o consultar la cantidad de registros. Cada evento almacena la fecha y hora, el identificador de sesión y la acción realizada, manteniendo una traza de auditoría ordenada. Además, permite consultar la cantidad total de registros y devuelve una copia de la traza que no puede modificarse desde el exterior, protegiendo los datos frente a modificaciones accidentales.
