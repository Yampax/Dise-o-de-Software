La clase ConfiguracionHospital implementa el patrón Singleton con inicialización diferida, mediante una instancia estática inicialmente nula, un constructor privado y el método getInstancia(), que crea el objeto únicamente cuando se solicita por primera vez. Los atributos son privados y cuentan con métodos para consultar y modificar los parámetros, incorporando validaciones para evitar nombres vacíos, duraciones no positivas y horarios incorrectos. Los módulos de recepción y consultorios acceden a la misma instancia, por lo que las modificaciones realizadas desde uno se reflejan inmediatamente en el otro. Finalmente, las comparaciones de identidad permiten comprobar que las llamadas posteriores a getInstancia() devuelven siempre el mismo objeto.
