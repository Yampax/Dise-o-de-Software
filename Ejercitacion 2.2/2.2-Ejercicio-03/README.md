La clase CatalogoL implementa el patrón Singleton mediante un constructor privado, una instancia estática y el método getInstancia(), garantizando que ambas pantallas compartan un único catálogo. La colección de libros permanece privada y las operaciones de incorporación, búsqueda y actualización se realizan mediante métodos controlados. Además, se validan los datos para evitar códigos duplicados, títulos vacíos y cantidades negativas. Las consultas devuelven listas no modificables para proteger la colección interna. La clase Libro representa cada elemento del catálogo y permite consultar sus datos. Finalmente, mediante la comparación de identidad se comprueba que ambas pantallas utilizan el mismo objeto y que las modificaciones realizadas desde una se reflejan en la otra.
