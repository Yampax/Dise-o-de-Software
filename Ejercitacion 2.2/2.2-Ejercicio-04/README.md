La clase Administrador implementa el patrón Singleton mediante un constructor privado, una instancia estática y el método getInstancia(), garantizando que ambos mostradores utilicen el mismo administrador. La colección de préstamos activos es privada y se modifica únicamente mediante métodos controlados. Al registrar un préstamo, se comprueba que el identificador del ejemplar no se encuentre registrado previamente, evitando préstamos duplicados. Las devoluciones eliminan el préstamo correspondiente y, si no existe uno activo, el estado permanece sin cambios. Además, se pueden consultar los préstamos activos de cada socio. La clase Prestamos representa cada operación y almacena el identificador del ejemplar, el socio y la fecha. Finalmente, la comparación con == demuestra que ambos mostradores comparten la misma instancia.
