La clase Biblioteca implementa el patrón Singleton mediante un constructor privado, una instancia estática y el método getInstancia(), que crea el objeto únicamente cuando es necesario y garantiza que los módulos compartan la misma instancia. Sus atributos son privados y cuentan con métodos de acceso y modificación que validan los datos para impedir nombres vacíos y valores numéricos menores o iguales a cero. Los módulos de préstamos y consultas obtienen la configuración mediante el método getInstancia(), por lo que cualquier modificación realizada se refleja en ambos. Finalmente, la comparación con == permite comprobar que los dos módulos utilizan el mismo objeto en memoria.
